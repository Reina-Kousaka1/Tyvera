# Support

Use the repository's [issue chooser](https://github.com/Reina-Kousaka1/Tyvera/issues/new/choose) and select the closest form:

- Reproducible compiler, runtime, or CLI problem: **Bug report**.
- General improvement: **Feature request**.
- Significant syntax, semantics, type-system, runtime, or compiler design: **Language Proposal / RFC**.
- Missing or incorrect docs: **Documentation issue**.
- General development or contribution question: **Development question**.

Security vulnerabilities belong in the private reporting path described in
[`SECURITY.md`](SECURITY.md), not a public issue. Do not post tokens,
passwords, credentials, private data, or `.tyvera.secrets` contents anywhere
in an issue.

The repository does not advertise a separate discussion forum. Use the issue
form that best fits the question; proposals are for design discussion and do
not imply that a change has been accepted.
